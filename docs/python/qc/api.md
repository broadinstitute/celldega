# Segmentation QC API Reference

Use `celldega.qc` to assess cell segmentation and transcript assignment from
instrument output. `qc_segmentation` writes summary and gene-level CSV metrics;
additional helpers compare expression patterns and cell classifications.

See the [Python overview](../index.md#qc-assess-segmentation-and-transcript-assignment)
for where QC fits in a workflow, and the
[custom segmentation example](../../examples/brief_notebooks/Custom_Segmentation.ipynb)
for importing an alternative segmentation into DegaFiles.
