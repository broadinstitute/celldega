# Align Module API Reference

`align` stacks the cells of serial sections in 3D, using clusters shared across
sections: cluster-centroid landmarks first, then neighborhood-overlap refinement.
Follow the [Broad–Allen mouse-brain preprocessing and alignment notebook](../../examples/tutorial_notebooks/Broad-Allen_Dev-Mouse-Brain_E15.5_Align.ipynb)
for both steps and the CellCloud export. Its [visualization companion](../../examples/tutorial_notebooks/Broad-Allen_Dev-Mouse-Brain_E15.5_Viz.ipynb)
opens the prepared data in linked views.
