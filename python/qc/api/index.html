    QC Module (in development)

    In development

    celldega.qc is not part of the documented API yet. Its functions may change or be removed without deprecation, and calling qc_segmentation or orthogonal_expression_calc raises a warning. The plan below describes where the module is headed.

    What it does today

    • qc_segmentation writes cell-level and gene-level metrics for one segmentation of a Xenium, MERSCOPE or custom dataset: the share of transcripts assigned to cells, cell counts and areas, and transcripts and genes per cell.
    • orthogonal_expression_calc compares segmentations by how often cells of one type contain transcripts of another type's marker genes.

    Both read instrument output folders directly rather than AnnData.

    Future directions: ectopic expression

    Spatial data let you check cells by eye, and one of the most useful checks is ectopic expression: a cell expressing marker genes of a different cell type, for example podocin (NPHS2) in a glomerular endothelial cell next to a podocyte. Ectopic expression can come from transcripts spilling over from a neighboring cell, from two cells segmented as one, or from real biology. The plan is to rebuild qc around it, replacing the two functions above.

    1. Calculate a cell type × marker set matrix. Inputs: cell-level AnnData, a cell-type column, and marker sets from prior knowledge (a dictionary, a .gmt gene-set file, or marker ranks). Entry (A, B) is how much cells of type A express type B's markers, such as the fraction of type-A cells with at least k type-B marker counts. The diagonal is on-target expression; the off-diagonal entries are ectopic.
    2. Add spatial context. For each ectopic cell, record how many of its spatial neighbors are of type B. Ectopic expression explained by neighbors suggests spillover or segmentation error; unexplained ectopic expression suggests doublets or biology. This can be a second layer, shown as dot size.
    3. Show it as a square Clustergram. Clustering groups cell types that share ectopic patterns, such as cell types that sit next to each other in the tissue.
    4. Review cells in a linked Yearbook. Clicking an off-diagonal entry (A, B) selects type-A cells ranked by their type-B marker expression with celldega.select, and pages them in a Yearbook with one marker of each type highlighted. Flagged cells come back to Python.
    5. Compare segmentations. One matrix per segmentation, side by side, replaces today's qc_segmentation comparison.

    A possible API:

    ectopic = dega.qc.calc_ectopic_expression(
    adata, cell_type="cell_type", markers=markers, min_counts=3, n_neighbors=10
)  # cell types x marker sets, with a neighbor-explained layer
mat = dega.clust.Matrix(ectopic)
mat.cluster()
dega.viz.Clustergram(matrix=mat)

review = dega.qc.select_ectopic(adata, source="Glomerular endothelium", target="Podocytes", markers=markers)
dega.viz.Yearbook(base_url=degafiles_url, cells=review.names())

    Until then, the ectopic expression review shows the review step with celldega.select and Yearbook.

    API

    Segmentation quality metrics from instrument output (in development).

    .. warning:: In development and hidden from the documentation. These functions may change or be removed without deprecation; calling qc_segmentation or orthogonal_expression_calc raises a UserWarning.

    qc_segmentation writes cell-level and gene-level metrics (transcript assignment, cell counts and areas, transcripts and genes per cell) for one segmentation of a Xenium, MERSCOPE or custom dataset. orthogonal_expression_calc compares segmentations by how often cells of one type contain transcripts of another type's marker genes.

    Future direction: rebuild the module around ectopic expression (cells expressing another cell type's markers), calculated from AnnData as a cell type x marker set matrix with spatial-neighbor context, shown as a Clustergram and reviewed in a linked Yearbook. The plan is on the unlisted docs page docs/python/qc/api.md.

    classify_cells(dataframe, cell_a_name, cell_b_name, threshold_for_a_cell_classification, threshold_for_b_cell_classification)

    Classify cells based on transcript thresholds.

    Parameters: - dataframe: Input dataframe - cell_a_name: Name of cell type A - cell_b_name: Name of cell type B - threshold_for_a_cell_classification: Threshold for classifying cell type A - threshold_for_b_cell_classification: Threshold for classifying cell type B

    Returns: - Dataframe with classification column added

    filter_orthogonal_expression(dataframe, cell_a_name, cell_b_name, threshold_for_orthogonal_exp)

    Filter cells with orthogonal expression.

    Parameters: - dataframe: Input dataframe - cell_a_name: Name of cell type A - cell_b_name: Name of cell type B - threshold_for_orthogonal_exp: Threshold for orthogonal expression

    Returns: - Tuple of proportions (A cells with B genes, B cells with A genes)

    orthogonal_expression_calc(base_paths, cell_type_a_specific_genes, cell_type_b_specific_genes, cell_a_name, cell_b_name, threshold_for_a_cell_classification=3, threshold_for_b_cell_classification=3, threshold_for_orthogonal_exp=3)

    Analyze orthogonal expression patterns of cell-type-specific genes across multiple segmentation algorithms.

    This function calculates the overlap of specific genes for two cell types (A and B) within cells across multiple segmentation algorithms. It returns per-technology transcript totals plus a classified summary of orthogonal expression, which can be plotted with any plotting library (e.g. a 2D histogram of the transcript totals, a grouped bar chart of the summary).

    Parameters

    base_paths : list of str List of paths to data directories cell_type_a_specific_genes : list of str List of genes specific to cell type A. cell_type_b_specific_genes : list of str List of genes specific to cell type B. cell_a_name : str Name or label for cell type A (used in output column names). cell_b_name : str Name or label for cell type B (used in output column names). threshold_for_a_cell_classification : int, optional Threshold for classifying cell type A (default: 3). threshold_for_b_cell_classification : int, optional Threshold for classifying cell type B (default: 3). threshold_for_orthogonal_exp : int, optional Threshold to perform orthogonal expression quantification (default: 3).

    Returns

    tuple of pandas.DataFrame (results, orthogonal_summary) where results has one row per cell (across all technologies) with per-cell-type transcript totals and classification, and orthogonal_summary has "Technology", "Category", and "Count" columns summarizing classified orthogonal expression per technology.

    Example

    results, orthogonal_summary = orthogonal_expression_calc( base_paths=["path/to/data1", "path/to/data2"], cell_type_a_specific_genes=["GeneA1", "GeneA2"], cell_type_b_specific_genes=["GeneB1", "GeneB2"], cell_a_name="CellTypeA", cell_b_name="CellTypeB" )

    qc_segmentation(base_path, technology=None, dataset_name=None)

    Calculate segmentation quality control (QC) metrics for imaging spatial transcriptomics data.

    This function computes QC metrics to assess the quality of cell segmentation and transcript assignment in spatial transcriptomics datasets. Metrics include transcript assignment proportion, cell count, mean cell area, and transcript and gene distribution statistics.

    Parameters

    base_path : str Path to the data directory path_output : str, optional Output path for results path_meta_cell_micron : str, optional Path to meta cell micron data

    Returns

    None Outputs two CSV files containing cell-level and gene-specific QC metrics.

    Example

    qc_segmentation(base_path="path/to/data")
