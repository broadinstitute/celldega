# Historical notebooks

These notebooks were moved out of the repository root to preserve early
development work. They are not maintained examples and may depend on removed
APIs, local files, or older data formats.

- `anywidget_counter_prototype.ipynb`: the original 2024 `Counter` widget prototype.
- `Visium-HD_pre-process.ipynb`: an early 2024 Visium HD preprocessing experiment.

For current workflows, use the [documentation examples](../../docs/examples/index.md).
