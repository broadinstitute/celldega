# Align Module API Reference

`align` stacks the cells of serial sections in 3D, using clusters shared across
sections: cluster-centroid landmarks first, then neighborhood-overlap refinement.

## Tutorials

- [Broad–Allen mouse brain preprocessing and alignment](../../examples/tutorial_notebooks/Broad-Allen_Dev-Mouse-Brain_E15.5_Align.ipynb):
  both alignment steps on serial Xenium sections of a developing mouse brain,
  and the CellCloud export.
- [Broad–Allen mouse brain visualization](../../examples/tutorial_notebooks/Broad-Allen_Dev-Mouse-Brain_E15.5_Viz.ipynb):
  the aligned cells in linked 3D views. Also in the
  [gallery](../../gallery/gallery_broad_allen_mouse_brain_3d.md).
